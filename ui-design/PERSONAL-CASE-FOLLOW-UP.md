# Coordination cases in My Work

Knowledge My Work now has a separate “My coordination follow-up” section. Only explicit case ownership selects records: Leo sees `current-workshop-brief`; Maya sees no owned cases. The unknown publication-policy owner is not inferred from role bindings or supplying/receiving assignments.

Case cards show next action, waiting context, unresolved status and links to the full case/shared goal. Ownership is follow-up responsibility, not assignment allocation, authorization or outcome verification. No resolution or action form is introduced.

Search and workstream filters apply to both assignment and case sections. Assignment role and work-attention flags apply only to assignments because no such allocation/response flags are declared for cases. Counts remain separate; hiding a case does not remove ownership. Filter clearing retains existing search-focus behavior.

Case → source → refreshed return preserves persona and the filtered My Work origin. Changing persona selects that person's explicit ownership. Current assignment counts, sidebar assignment badge and allocation data are unchanged. Main/larger have no new case section or inherited Knowledge cases.

# Responsibility proposal demo

From Organization attention → Responsibility, or the overview's expandable Responsibility gaps, select Propose responsibility. Choose a sample worker, inspect the fixed role/scope and give a reason. Record local proposal creates a session receipt that can be reopened from either entry. Remove local proposal discards it; refresh clears all proposals.

The implementation gap proposes a Developer for Team invitation improvements. The assessment gap proposes a Reviewer for the same stream. Candidate choices are authored examples, not availability/capability checks. Alex's existing Team Workspace reviewer binding does not create an invitation assessment assignment. Codex's payment scope does not grant an invitation developer binding.

A proposal is coordination intent awaiting allocation. It does not modify bindings, permission, assignment ownership or attention counts; both gaps remain open. The role and scope are fixed to the selected gap, and rationale is required. No external request is sent. The flow illustrates a step toward a future allocation decision rather than implementing that decision.

The shared modal contains keyboard focus, closes with Escape and returns focus to its entry. After recording, focus moves to the receipt heading. Canceled forms are discarded; there is no draft persistence for this small flow.

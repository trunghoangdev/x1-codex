# Actionable organization attention

Iteration 101 adds a compact **Coordination needs to inspect** list to Knowledge Organization, with a complete category-filtered list in Organization attention for Knowledge and larger software. Main software attention now names affected subjects, represented responsibility, waiting reason and suggested inspection steps.

Each signal separates its subject, reason, known responsibility, suggested next step and navigation destination. An assignment assignee or waiting recipient is not automatically a follow-up owner. Missing follow-up/escalation ownership remains explicit. Suggestions are UI guidance, not admitted task allocation. No deadline, urgency rank or completion percentage is invented.

## Contribution transitions

The shared Knowledge contribution can add one local Response signal:

- Delivered revision without receipt: Maya is the sample receiver; open Maya's My Work to inspect and receive that exact contribution.
- Recorded draft-01 revision request before draft-02 preparation: Leo is the sample contributor; open the contribution to inspect the request and prepare its revision.
- Pending/unknown command or admitted command awaiting delivery projection: open Leo's command context; do not imply failure or permission to resend.

No unsubmitted draft creates a missed-deadline signal. Receipt clears the receipt need but does not accept the contribution. Starting draft-02 clears the unstarted-revision signal without completing the revision or outcome. Authored outcome gaps remain independent. Organization attention category totals and its complete list use the same signal projection; other authored coordination/workstream counters are not live projections of contribution state.

The compact list shows at most three signals: local contribution observation first when present, then authored source order. This is not urgency sorting. Existing View all organization attention opens the complete list. Authored input links open the waiting assignment and its provider context. Local contribution links select the responsible sample persona; this is navigation, not authentication or effective authority.

## Limits and checks

Knowledge local records remain session-only and excluded from Demo continuity. Larger software is authored inspection. Main software preserves its existing local-response signal behavior. No backend, new assignment allocation, evidence verification or external effect is introduced.

Browser/model checks cover exact receiver navigation, missing-input/category inspection and source return, contributor/receiver revision loops, clearing bounded needs without closing outcome gaps, and existing Knowledge personal navigation on desktop/phone. Tests are technical checks, not participant research.

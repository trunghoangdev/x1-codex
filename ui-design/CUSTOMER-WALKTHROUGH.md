# Supplemental software customer tour

For the current organization-first presentation, use [WALKTHROUGH.md](WALKTHROUGH.md). The older eight-step in-app tour below remains a separate main-software example.

Open Demos and select Start customer walkthrough. The guide stays above the current screen. Previous step and Next step open the authored destinations; Open this step returns to the selected destination after exploring links or browser history. The step indicator tracks the selected guide step, not task completion or the current URL. Finish or Exit returns to Demos without clearing existing local records. Refresh ends the guide; main sample state may restore its last saved Demo continuity snapshot.

The eight stops are Organization Overview, invitation workstream, Alex's role bindings, responsibility attention, optional responsibility proposal, My Work, A-1042 evidence and payment outcome review. Proposal recording and assessment recording are optional: advancing never claims either happened.

The story deliberately changes subjects after invitation coordination. Invitation implementation and assessment are missing, so payment review provides the evidence example. There is no implied invitation-to-payment dependency, automatic allocation or single end-to-end run. A-1042 is an assessment; production release authorization remains a separate decision about its exact release subject.

Customer message: a virtual organization connects goals, scoped human/AI/deterministic responsibilities, personal assignments and inspectable records. It also exposes missing responsibility and missing proof. A local response does not establish that the business goal was achieved.

All data is authored sample data. The guide does not integrate with SF, issue external requests, validate worker capacity or grant permissions. Main workspace receipts and proposals are preserved when starting/exiting the guide; reload may restore the last explicitly saved main snapshot. The independent revision and larger organization demos remain separate.

For a live presentation, use a fresh browser profile if a clean scenario is desired. Explain the organization first, optionally record an invitation proposal, then inspect payment evidence and conclude with the still-unverified outcome. Use the larger organization demo separately when discussing scale.

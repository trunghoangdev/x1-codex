# Workstreams directory

Organization Overview → Browse workstreams opens `#/organization/workstreams`. Search matches stream ID, name, project and goal. Project and Attention signal filters combine with the search. Clear filters restores all streams. Filters replace the current URL entry, so typing does not create a history entry for every keystroke; refresh and browser history restore the URL's filters.

The directory uses the two streams from the main sample organization. It does not merge the independent larger organization scenario. It reuses explicit responsibility gaps and outcome evidence requirements rather than deriving health from assignment completion. Missing responsibility selects streams with an explicit gap. Unverified outcome selects streams with outstanding sample outcome evidence gaps. Both current streams remain unverified; only invitation has explicit responsibility gaps. No explicit gap recorded does not assert complete staffing or capacity.

Each entry shows its goal, project, responsibility gaps, outcome context and authored linked assignment count. Open workstream opens the existing detail view. Back to Workstreams remembers that directory URL in the session. Refreshing a detail loses that source context and falls back to Organization. Main navigation clears directory source context. Proposals and assessment receipts never resolve directory signals.

The view has a mobile card layout, labeled filters, result announcement and an empty state. No backend requests, pagination or total organization health score are introduced. The small sample does not validate performance for a large live organization; a shared scenario/provider and paging remain future work.

# Forge workspace exploration

- [Interactive UI prototype](ui-design/README.md) — English Software Factory workspace with My Work, assignment review, authority decisions, organization roles, and evidence inspection.
- [UI design specification](ui-design/DESIGN.md) — screen intent, interaction rules, visual direction, and production boundaries.
- [Customer introduction](customer-introduction.md)

To open the prototype:

```sh
cd ui-design
npm ci --cache ../.cache/npm
npm run dev
```

Open the localhost URL printed in the terminal. All prototype data is fictional; actions reset on refresh.
